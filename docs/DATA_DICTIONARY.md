# Data Dictionary

## Project
E-Commerce Business Intelligence Dashboard

## Purpose
This document describes the main fields and metrics used in the Excel dashboard.

## Key Metrics

| Metric | Description |
|---|---|
| Net Sales | Net sales value |
| Profit | Profit generated from sales |
| Quantity | Number of units sold |
| Orders | Number of orders |
| Category | Product category |
| Subcategory | Product subcategory |
| State | Geographic sales information |
| Order Status | Current order status |

## Notes
Actual field names and calculations depend on the source dataset and Excel workbook.
